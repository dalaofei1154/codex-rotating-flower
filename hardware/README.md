# 雏菊模型与打印文件

当前整理版本为 [雏菊带灯版](daisy-light/README.md)：一套 **10 件成品、13 个分色 STL、9 个打印工程、10 个可编辑 Blender 网格场景**。

只收录无品牌标志的雏菊、枝干、花盆与结构件；不含 OpenAI / WorkBuddy 标志花盘、第三方原手动模型、未选变体和机型专用 G-code。模型采用 **CC BY-NC-SA 4.0**，完整授权范围及商用联系以本目录许可文件和项目 `LICENSES.md` 为准；仓库代码的 MIT 许可不自动适用于模型。

这套模型整理于 2026-11-05，公开资料更新于 2026-11-06。作者的 L2 盖＋P4 灯帽样机已装好，转动和亮灯正常。花心、透明灯帽、枝干与盆盖的连接还有些松，后续会继续改进；打印后请逐处试装，搬动时托住盆体。
