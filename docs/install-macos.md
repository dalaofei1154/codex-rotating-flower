# 安装小花联动 · Mac setup

小花通过 USB 连接 Apple 芯片 Mac，支持 Codex、WorkBuddy 和 DeepSeek Harness（DSH）的旋转与提醒灯联动。小花后台需要 macOS 12+，DSH 适配需要 macOS 13+。

## 双击安装

**[查看统一安装指南](open-release/INSTALL.md#zh)**：下载 v0.7.0 安装包，解压后双击 `安装小花.command`。使用 DSH 时，先打开一次 DSH 完成本机配置初始化，安装后再退出重开。指南包含硬件准备、安装、升级、卸载和常见退出码。
