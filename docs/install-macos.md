# 安装小花联动 · Mac setup

小花通过 USB 连接 Apple 芯片 Mac，支持 Codex 和 WorkBuddy 的旋转与提醒灯联动。

**[查看统一安装指南](open-release/INSTALL.md#zh)**：下载 v0.6.0 安装包，解压后双击 `安装小花.command`。指南包含硬件准备、安装、升级、卸载和常见退出码。
