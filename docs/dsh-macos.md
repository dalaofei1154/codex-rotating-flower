# DeepSeek Harness 小花适配（v0.7.0 本地试用）

已在 DeepSeek Harness **0.2.1-rc.5** 的 Apple 芯片 Mac 上完成联动测试。此页描述本地 v0.7.0 安装包；GitHub 公开的 v0.6.0 安装入口尚不包含 DSH。

## 安装

使用已烧录旋转＋提醒灯固件的小花、USB 数据线、Apple 芯片 Mac。小花运行环境支持 macOS 12+；此次 DSH 应用本身要求 macOS 13+。

解压 `RotatingFlower-Mac-v0.7.0.zip`，双击 `安装小花.command`。安装器按应用 bundle ID 自动识别 Codex、WorkBuddy、DeepSeek Harness，启用已安装的全部来源。内带 Python，无需另装 Node、Python、Homebrew 或填写 API Key。

DSH 的接入使用其本地插件层，安装器会保留并备份原有 `~/.dsh/profiles/desktop/cordis.patch.yml`，只添加带明确起止标记的小花插件项。当前版本实测可以热加载；若提示等待 DSH，打开或重启 DSH 一次即可。卸载器移除该项，保留其他插件、设置与备份。

## 档位及提醒

| DSH 推理等级 | 小花档位 |
| --- | --- |
| Off | LOW |
| Low | MEDIUM |
| High | HIGH |
| Max | ULTRA |

缺失档位保守使用 LOW，未知非空档位使用 HIGH。其他模型如提供 medium、xhigh，分别使用 MEDIUM、XHIGH。这是模式映射，不表示实测算力、token/s 或 RPM。

- 工作中旋转，完成或取消停止。
- 阻塞式问题或授权等待：该任务停转并亮呼吸灯；回答、拒绝、取消后清除对应等待。
- 异步继续的问题：提醒保留，但不强制停止仍在工作的任务。此分支已做自动化测试，尚未单独完成真实异步问题卡验证。
- 多应用／多任务取最高工作档位，提醒取任一来源的待处理状态。DSH 等待时，正在工作的 Codex 或 WorkBuddy 可以继续贡献旋转。
- DSH 退出、心跳超过 3 秒或进程消失后，不贡献旋转和灯；其他正常来源继续工作。重开 DSH 自动恢复。

## 本地数据与边界

小花观察插件只读 DSH 运行时的 agent 状态、所选模型和推理等级、问题/授权的数量与未完成标记，每 500 毫秒原子写入本机 `~/Library/Application Support/RotatingFlower/dsh/status.json`。不读取账号凭据，不发送网络请求，不输出问题正文、回答、工具命令或聊天内容，不替用户作授权决定。它只写自己的状态文件，不修改 DSH 对话。

桥接程序通过同一个串口管理器驱动硬件，不给 DSH 创建第二个串口竞争者。输入文件限制大小、格式与时间新鲜度，异常时停止该来源输出。插件只随明确允许的文件打包，用户配置和会话不进安装包。

接入依赖 DSH 的插件与运行时接口，应用更新后应复测。当前没有对所有 DSH 版本、第二台 Mac、长期连续运行做验证；本次测试硬件回执通过，仍待用户目视确认实际旋转与灯光。
